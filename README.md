# Скринкаст «защита диплома»

**Файл:** `скринкаст защита диплома.mov` (~8 МБ, формат QuickTime `.mov`)

## Назначение

Видеодемонстрация веб-приложения **«Школьный журнал ФК»** — материал к защите выпускной квалификационной работы по теме учёта спортивных достижений на уроках физической культуры в начальной школе.

На записи показана работа с основными разделами приложения: классы и ученики, журнал нормативных результатов с расчётом баллов, рейтинги и турнирная сетка.

## Связанные материалы

- `../1.2 - преза/Презентация_защита_ВКР.pptx` — слайды выступления  
- `../1.6 - тезисы к защите/Тезисы_доклада_предзащита.docx` — тезисы доклада  
- исходный код приложения — папка «Дипломная работа»

## Просмотр

Открывается в **QuickTime Player**, **VLC** или встроенном проигрывателе macOS. Для загрузки на GitHub или в LMS при необходимости конвертируйте в MP4.
